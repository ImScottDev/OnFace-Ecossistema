## Leitura consolidada das jornadas
- **Núcleo comercial (1–7) funciona** com evidência histórica robusta e parte em runtime (server actions do bloco vendas não dependem do proxy morto). É o trecho mais sólido do produto.
- **Pós-venda (8–14) é frágil**: clientes/CS materializados por batch único, riscos/renovações/marcos zerados localmente (existiam em 20/09), telas dependentes do proxy morto ou placeholder. É onde a paridade com o que já existiu está mais ameaçada.
- **Assinatura é o elo perdido** de ponta a ponta: o contrato existe, é faturado, mas não há prova de assinatura em nenhum dos 745.
- **Fronteira de prova**: nenhuma jornada foi exercida com sessão autenticada neste runtime; a prova de "funciona hoje" para as telas do redesign depende de (a) sessão e (b) API viva na porta certa — hoje ausentes localmente.
