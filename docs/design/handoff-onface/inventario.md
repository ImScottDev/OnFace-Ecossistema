## Proposta de colapso da escala

Nada disto foi aplicado. A camada de token preserva todo valor do desenho.
Cada linha é uma junção possível entre vizinhos a 1px ou menos, e o **custo**
é quantas declarações mudariam de valor se ela fosse feita.

### Tamanho de fonte

| junção | diferença | declarações afetadas |
|---|---:|---:|
| `15.5px` → `15px` | 0.5px | 2 |
| `9px` → `9.5px` | 0.5px | 3 |
| `14.5px` → `14px` | 0.5px | 11 |
| `10px` → `10.5px` | 0.5px | 34 |
| `13.5px` → `13px` | 0.5px | 48 |
| `12px` → `12.5px` | 0.5px | 110 |
| `11.5px` → `11px` | 0.5px | 129 |

As 7 junções são independentes — dá para aceitar umas e recusar outras.
Aceitando todas: **337 declarações** mudam de valor e a escala vai de 
24 para 17 degraus.
